📈 なぜ2ヶ月で伸びるのか

採点者が見るのは「頭の良さ」ではなく、設問に答えているか・主張を根拠で支えているか・型どおり構成されているか。これは訓練で身につく技術です。伸びる人の3原則：

  1. 型を固定する：毎回同じ5段落の設計図で書く。悩む時間が消え、中身に集中できる。
  2. 量をこなす：2ヶ月で約50本＝週6本。手が型を覚えるまで書く。
  3. 毎回フィードバック：書きっぱなしにしない。採点→弱点を1つ直す→次に活かす。

⏱ 小論文1本の書き方（60分の配分）

  1. 設問を読む（2分）：問われている言葉に線を引く。「何を答えれば正解か」を確認。
  2. 構成メモ（8分）：5段落の骨子を単語で書く。主張を一文で先に決める。
  3. 執筆（40分）：メモどおりに書く。手書き・原稿用紙で。
  4. 見直し（5分）：誤字、主述のねじれ、設問に答えているかを確認。
  5. 自己採点（5分）：下の6基準で○△×。一番低い基準を次回の重点に。
鉄則：メモなしで書き始めない。主張を決めずに書くと、必ず途中で崩れます。

🔁 毎日の習慣（各15〜30分・書かない日も続ける）

  • 音読：模範小論を1本、声に出して読む。合格の文章のリズムが体に入る。
  • 写経：模範を1本、原稿用紙に書き写す。型と接続表現（もちろん〜だが等）が手に馴染む。
  • ネタ帳：留学の場面・読んだニュースを1件、3行でメモ。本番で使うカードを貯める。
  • ニュース1本：国際・社会面から1本読み、「自分の意見＋理由」を一言。時事対策と面接対策を兼ねる。

✅ 自己採点のしかた（6基準・各5点）

書いたら毎回この6つを自分で採点します。満点の条件を平易にすると：

  • 課題文理解：（課題文型のとき）筆者の主張を正しくつかめているか。
  • 設問対応：問われたことにまっすぐ答えているか（ずれが一番多い失点）。
  • 主張の明確さ：「私は〜と考える」が一文で言えているか。
  • 論理と根拠：主張に理由と具体例がついているか。飛躍がないか。
  • 具体性・視野：自分だけの体験＋社会への広がりがあるか。
  • 日本語表現：誤字・主述のねじれ・話し言葉がないか。

合計24以上で合格圏。「採点表」タブに詳しい基準、「採点記録」タブに点数の推移が出ます。

面接対策

入門レッスン→質問バンクから「想定問答ノート」を作る→模擬面接（元先生と実践）の順で進めます。

提出した志願書に書いた一文一文が、そのまま質問になります。上智の面接は志望理由書を軸に進むため、ここに挙げた質問に答えられる状態を作ることが最優先です。面接官は、志望理由書・小論文・面接の答えが一つの軸（なぜFGSか・何を学ぶか・将来へどうつなぐか）で貫かれているかを、質問を変えて何度も確かめます。すべての答えをこの軸に戻すこと。各問の「狙い」で何を見られているかを把握し、「答え方」を参考に自分の言葉で骨子を作ってください。「想定問答ノートへ」を押すと、答えを書き込めるノートに追加されます。

⚠️ 本番までに必ず準備すること

  1. 読んだ本の名前を2つ以上言えるようにする。「帰国後に調べる中で」と書いた以上、必ず問われます。読んでいない本は絶対に挙げないこと。
  2. 「当事者とともに歩む支援」を20秒で説明できるようにする。志願書の中心概念なので、ここが空白だと全体が崩れます。
  3. 「英語を教えたのは押しつけではないか」への答えを用意する。志願書の主張と行動の整合性を突く質問で、鋭い面接官なら必ず聞きます。
  4. 地域研究はアジアか中東・アフリカのどちらを選ぶか決めておく。貴学部にラテンアメリカ研究はありません。
面接練習の基本：自分の声を録音して聞き返す。答えを文章に書いて覚えるのは禁止です（棒読みになります）。骨子（キーワードの箇条書き）だけを見て話し、スマホで録音→聞き返すと、自分では気づかない話し方のクセが見えてきます。

バックアップ

すべての記録をJSONファイルとして書き出します。ブラウザを変える時や万一に備えて定期的に保存してください。

復元

書き出したJSONファイルを読み込んで復元します（現在のデータは上書きされます）。

危険な操作

※「サイトデータを消去」などブラウザの履歴削除を行うとデータが消えます。必ず同じブラウザ（SafariかChromeに固定）で開いてください。
